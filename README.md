# 译舟 V6：可信编程教练

面向高校 Python 数据分析与跨专业编程课程的本地优先教学智能体原型。

本仓库同时保存三项参赛材料对应的共同技术底座：

- 教学创新大赛项目名：**问数航标**
- AI+教学赛道项目名：**译舟**
- 实验教学案例项目名：**像素证签**

三项作品共享代码和数据治理方法，但申报叙事、课堂对象和证据结构分别设计。

这一版不再以“万能问答”为目标，而是把一次求助拆成可核查的教学过程：

1. 识别报错与代码特征。
2. 定位课程知识图谱中的前置概念。
3. 按提示阶梯给出追问、自查点和最小修改方向。
4. 要求学生运行、解释并确认结果。
5. 记录匿名学习事件，形成班级共性问题和教师干预队列。
6. 为每次回答生成证据摘要与内容摘要，便于复核和后续审计。

## 当前功能

- 本地优先，未配置外部模型也可运行。
- Python 报错分类与知识点映射。
- 提示阶梯，不直接代写完整作业。
- 课程图谱与前置知识回溯。
- 学生复核确认与 AI 使用留痕。
- 班级学习脉冲、错误热点和风险提示。
- JSON、CSV 数据导出。
- OpenAI 兼容接口的预留适配层。
- 数据来源标记，真实试用与过程样例分开保存。

## 快速运行

```bash
cd work/yizhou-v6
python3 scripts/seed_demo.py
python3 -m yizhou_lab serve
```

浏览器打开：

```text
http://127.0.0.1:8765
```

静态可视化首页位于`docs/index.html`，可由GitHub Pages直接发布。

也可以直接运行：

```bash
./run.sh
```

## 命令行

```bash
python3 -m yizhou_lab feedback \
  --code "counts[word] += 1" \
  --error "KeyError: 'the'"

python3 -m yizhou_lab analytics
python3 -m yizhou_lab export --output exports/evidence.json
```

## 数据边界

`scripts/seed_demo.py`用于生成流程样例事件。数据来源、真实试用和样例数据的边界统一记录在`application/数据来源说明.md`。

## 目录

```text
yizhou_lab/       核心后端
web/              本地单页界面

tests/            自动化测试
docs/             架构、数据治理和扩展说明
```
